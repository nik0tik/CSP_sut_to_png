    Как этим пользоваться и что означают настройки
    
    

      
    Что это делает
    
      
    Файл .sut — это база данных SQLite, внутри которой лежат
         настройки кисти и её картинки: наконечники (brush tips), текстуры,
         превью. Инструмент открывает базу, находит внутри все целые PNG и
         складывает их в понятную структуру папок.
    
      
    Что он не делает: не вытаскивает настройки кисти, не
         создаёт .txt и .sql, не меняет ваши файлы
         .sut и не превращает картинки обратно в кисть. На выходе
         только PNG.
    
      
    
        
    Нужно вытащить из кисти вообще всё, а не только картинки?
           Воспользуйтесь
           Clip Studio Brush
           Extractor.
    
      
    

      
    

      
    Быстрый старт
    
      
      
        
    1. Перетащите папку с кистями в пунктирную рамку выше.
            Или нажмите Выбрать папку и укажите её вручную.
      2. 
        
    2. Дождитесь, пока полоса прогресса дойдёт до конца — под ней появятся

    Настройки
    

      
    Искать во всех таблицах
    
      
    По умолчанию инструмент читает только то место, где Clip Studio хранит
         наконечники кисти.
    
      
    Включите галочку, если из какой-то кисти ничего не извлеклось. Тогда
         просматриваются все таблицы базы целиком — находится больше, но вместе
         с наконечниками попадут текстуры бумаги, альфа-маски (выглядят как
         простые серые формы) и мелкие превью для панели инструментов.
    
      
    Порядок действий обычно такой: сначала попробуйте без галочки, и только
         если результат пустой — с галочкой.
    

      
    Пропускать меньше N px
    
      
    Отсекает картинки, у которых любая сторона меньше указанного числа
         пикселей. Нужно, чтобы отфильтровать превью-миниатюры.
    
      
      
        
    • 0 — не отсекать ничего (по умолчанию).
      • 
        
    • 64 — типичное значение, убирает иконки и мелкий мусор.
      • 
        
    • 128 — если нужны только крупные наконечники.
      • 
      
    
      
    Сколько картинок отсеялось, видно в отчёте и в плитке с цифрами.
    
      
    Настройки применяются при следующей обработке. Если поменяли галочку
         после того, как результат уже получен — перетащите папку заново.
    

      
    

      
    Что показывается на экране
    
      
    Полоса прогресса и статус — сколько кистей обработано
         из общего числа. На больших папках статус обновляется на ходу,
         страница не подвисает.
    

      
    Плитки с цифрами:
    
      
    
        
          
    ПлиткаЧто значит
    
            
        
          
    картиноквсего PNG готово к сохранению
    
          
    кистейиз скольких .sut что-то извлеклось
    
          
    без картинокфайлы, где не нашлось ни одного PNG
    
          
    отсеяноотброшено фильтром по размеру
    
          
    с ошибкамифайлы, которые не удалось прочитать
    
            
      
    
      
    Последние три плитки появляются только если такие случаи были.
    

      
    Превью — первые 24 картинки на шашечном фоне. Шашечки
         нужны, чтобы были видны прозрачные наконечники: без них белая кисть на
         белом фоне выглядела бы как пустой квадрат. Наведите курсор — увидите,
         из какой кисти картинка.
    
      
    Превью показывает только начало; в результат попадают все найденные
         картинки, не только показанные.
    

      
    Подробный отчёт — свёрнутый блок выше. Разверните,
         чтобы увидеть построчно каждую кисть, сколько из неё извлечено и какие
         размеры у картинок, например [400x400, 32x32]. По размерам
         удобно понять, что лишнее, и подобрать значение для фильтра.
    

      
    

      
    Важно
    
      
      
        
    • Ничего не сохраняется между сессиями. Закрыли страницу — результат
            исчез, надо обрабатывать заново.
      • 
        
    • На телефонах и планшетах выбор папки работает плохо или не работает
            вовсе: мобильные файловые менеджеры обычно не дают браузеру доступ к
            папке целиком. Отдельные файлы выбрать можно. Для больших наборов
            лучше сесть за компьютер.
      • 
      
    

    
    
  
    

  
    Разбор идёт целиком в браузере. Файлы кистей не изменяются.
